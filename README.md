# vencord-pgp-signature

A stealthy, context-bound OpenPGP signature plugin for [Vencord](https://vencord.dev) (Discord Desktop & Vesktop).

It digitally signs your outgoing Discord messages using your local **GnuPG / YubiKey (OpenPGP Smartcard)** and steganographically conceals the cryptographic signature inside the text using invisible zero-width Unicode characters. 

The message reads as clean, standard text to all users. Anyone using the plugin can right-click the message to inspect the full OpenPGP cryptographic proof, identity, key fingerprint, timestamp, and envelope metadata.

---

## 🔒 Key Features

* **Hardware Token / YubiKey Integration**: Leverages your local `gpg-agent`. Private signing keys never leave your secure hardware token.
* **Silent & Responsive UX**:
  * **2s Intelligent Prompt**: If signing is fast (< 2s), sending is 100% silent and instantaneous. The "Touch your YubiKey" notification only appears if signing is waiting for your physical touch or PIN.
  * **Pristine In-Chat UI**: Messages that are verified valid or ordinary unsigned messages display no visual clutter. A visible red alert badge (`⚠`) only appears if a message is actually broken, tampered with, or sent by a pinned contact without a signature.
* **Right Click $\rightarrow$ "Verify PGP Integrity"**:
  * Detailed modal breakdown showing: Verification verdict, Signer UID, Email, Key ID, Full Fingerprint, Signature Timestamp, exact Canonical Signed Text, and Technical Envelope / Alphabet details.
* **Channel Policy & Pre-Activation Support**:
  * Signing is granularly enabled per-channel (`Right click channel -> Sign messages here`).
  * Historical messages sent *before* enabling PGP in a channel are cleanly identified as `○ Unsigned (Sent before enabling PGP)` rather than false alarm errors.
* **Automatic Public Key Detection & Import**:
  * When someone posts a `.asc`, `.key`, `.gpg`, or `.pgp` attachment or pastes an armored block, a discrete card offers to **`Add to keyring`** (importing & pinning the contact) and **`Sign messages here`**.
  * Settings includes an **`Upload .asc / .key file`** file picker for manual offline public key imports.
  * Automatic network resolution via WKD, Keyoxide, `keys.openpgp.org`, and Ubuntu keyserver.
* **Zero-Width Alphabet (`base4`)**:
  * Standardized on the 4 Unicode zero-width characters (`U+200B`, `U+200C`, `U+200D`, `U+2060`) with a `U+034F` anchor.
  * 100% immune to Discord gateway sanitization and zero-width stripping.

## 🛡️ Security Model: Context Binding (v2)

Signing bare text is vulnerable to replay and cross-channel relocation. A signature generated by this plugin covers an authenticated canonical envelope:

```
ipgp2\n<len>:discord\n<len>:<channelId>\n<len>:<authorId>\n<len>:<timestamp>\n<len>:<attachments>\n<visible text>
```

### What this guarantees:
* **Anti-Tampering**: Editing a single character invalidates the cryptographic signature immediately.
* **Anti-Relocation / Cross-Channel Spoofing**: Copying a signed message and its invisible payload into another channel or DM causes verification to fail (the channel ID mismatch is caught by the receiver).
* **Anti-Impersonation**: An attacker cannot change the author ID or claim someone else's signature.
* **Anti-Replay**: Signatures are tied to a UTC timestamp window. Old messages replayed outside the tolerance window are flagged as `Replayed`.
* **Trust-on-First-Use (TOFU) & Pinning**: When an enrolled contact signs with a different key, the plugin flags `KeyChanged` to prevent key substitution attacks.

## 🚀 Installation & Setup

Because custom user plugins require native Electron bridge hooks for GnuPG, the plugin is loaded into your Vencord build.

### Prerequisites
* [Node.js](https://nodejs.org) (v18+) & [pnpm](https://pnpm.io)
* [git](https://git-scm.com)
* **GnuPG** (`gpg` installed and available in your `PATH`)
* A GPG signing key (or YubiKey configured with OpenPGP)

### 1. Build Vencord with the Plugin

```bash
# 1. Clone Vencord
git clone https://github.com/Vendicated/Vencord.git
cd Vencord
pnpm install --frozen-lockfile
pnpm add openpgp

# 2. Copy the plugin
mkdir -p src/userplugins
cp -r /path/to/vencord-pgp-signature/src/plugins/invisiblePgp src/userplugins/

# 3. Build Vencord
pnpm build
```

### 2. Inject into Discord / Vesktop

* **Discord Desktop**:
  ```bash
  pnpm inject
  ```
* **Vesktop**:
  Open Vesktop Settings $\rightarrow$ *Vencord Location* $\rightarrow$ select the `dist` folder inside your Vencord build directory.

Restart Discord completely (`Ctrl + Q` or quit from tray).

### 3. Enable in Discord

1. In Discord Settings $\rightarrow$ **Plugins**, toggle **`InvisiblePGP`** ON.
2. Right-click any channel or DM $\rightarrow$ **`Sign messages here`**.
3. Send a message! Your YubiKey or GPG agent will sign the message cleanly.

* **In Chat**: 
  * Valid signatures: Clean and invisible.
  * Compromised / Tampered signatures: Red inline alert (`⚠`).
